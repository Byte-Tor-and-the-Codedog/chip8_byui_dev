# BYUI Chip8 Dev Emulator

Simple Chip8 Emulator for BYUI teaching dev board.

## Instructions for Build and Use

1. Download code
2. Open file in Vscode
3. Make sure you have relevant libraries
4. Make sure libraries have the correct settings
5. Change workingRom variable to the game you want.

Instructions for using the software:

1. First select the desired rom.
2. Make sure Keypad is connected
3. Upload code to dev board
4. Play

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* TFT_eSPI.h
* ArduinoIDE
* Keypad.h
* time.h
